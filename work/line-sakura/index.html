LINEミニアプリ · クリニック

待合室ではなく、
家で待つ

内科・小児科の「さくら通りクリニック」。家からLINEで順番を取り、いま何番を呼んでいるかをいつでも確認。あと3人になったらLINEでお知らせが届くので、混んだ待合室で長く待たずにすみます。

患者さんの画面

順番を取ってから呼ばれるまで、5つの画面

すべてLINEの中で完結します。アプリのインストールも、会員登録もいりません。

  1. いまの呼び出し状況呼び出し中の番号と、お待ちの人数、待ち時間の目安。
  2. かんたんな問診受診する方、診療科、初診か再診か、いまの症状。
  3. あなたの番号あなたの前に何人か。呼び出しが進むたびに変わる。
  4. お呼び出しあと3人でLINEにお知らせ。順番が来たら、診察室を案内。
  5. 診察のあとお会計のお呼び出しや、予防接種のご案内もLINEで。

クリニック側の画面

LINEと窓口が、一つの列に

受付のパソコンやタブレットで、LINEの受付と窓口の受付が同じ列に並びます。「次の方を呼ぶ」を押すと、患者さんのスマホにも届きます。

  • LINEと窓口の受付が、一つの列に並ぶ
  • 診療科・初診か再診か・発熱の有無が、ひと目でわかる
  • 「次の方を呼ぶ」で、患者さんのスマホも進む

課題

冬になると、待合室は熱のある子どもと保護者でいっぱいになります。一時間以上待つことも珍しくなく、うつしあいも心配でした。家で待ってもらい、順番が近づいたら来てもらう。それを電話ではなく、いつものLINEでできるようにしたい。

つくったもの

  1. LINEのリッチメニューから開く順番受付。会員登録もパスワードもいらない
  2. いま呼び出し中の番号と、お待ちの人数、待ち時間の目安をトップに
  3. 受診する方・診療科・初診か再診か・症状を選ぶ、かんたんな問診
  4. 発熱を選ぶと、院内に入らず別の入口へ案内
  5. あと3人でLINEにお知らせ。呼び出しも、お会計もLINEで
  6. 受付の画面で、LINEと窓口の受付を一つの列に

設計で決めたこと

  1. 待つ場所を、家に待合室にいる時間が短いほど、患者さんも楽で、うつしあいも減ります。
  2. 知らせるのは、少し前に「あと3人」で知らせれば、家から歩いて間に合います。人数は医院ごとに変えられます。
  3. 発熱の方は、別の動線で問診で発熱を選んだ方には、到着しても院内に入らないよう最初から伝えます。
  4. 窓口の受付も、同じ列でスマホを使わない方も、これまでどおり窓口で。順番はLINEの受付と同じ列に並びます。

実際の導入に必要なもの

  • クリニックのLINE公式アカウント
  • LINEミニアプリのチャネル（LINEヤフーの審査は通常1〜2週間）
  • 受付システムとのつなぎ込み、または受付用の画面だけで始める
  • 問診の内容は医療に関わる情報のため、保存のしかたと同意の取り方を医院と一緒に決めます
  • 受付用のタブレットかパソコン
