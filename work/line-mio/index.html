席を守る、
LINEの予約

神楽坂の寿司店「鮨 澪」。カウンター8席・二回転。LINEで空席を見てコースと人数を選び、カードを登録して席を確保。前日にはLINEで来店を確認し、キャンセルが出た席はキャンセル待ちの方へ自動でお知らせします。

ライブデモ

自動で動いています。画面に触れると、そのまま操作できます。

お客さまの画面

予約から前日の確認まで、5つの画面

お店のLINEのトーク画面の下のメニューから開きます。名前はLINEのプロフィールから入るので、入力はほとんどありません。

  1. コースと人数日本酒のペアリングも選べて、お会計の目安がすぐに出ます。
  2. 日と回を選ぶ○△×で空席がひと目でわかり、満席の日はキャンセル待ちに。
  3. カードで席を確保本日の請求は¥0。キャンセルポリシーは確定の前に。
  4. 予約の確定このあとLINEに届くものを、先にお知らせします。
  5. 前日の来店確認ボタンひとつで「来店します」。キャンセルもここから。

お店側の画面

保証と確認が並ぶ、予約台帳

その夜の二回転ぶんの席と予約が、一枚に。カードや予約金で保証された予約か、前日の確認が取れているかが、ひと目でわかります。

  • 電話の予約は「保証なし」と表示。電話をかけるべき相手がわかる
  • 前日の来店確認の返事が、台帳にそのまま入る
  • キャンセルが出たら、空いた席をキャンセル待ちの方へLINEでお知らせ

課題

神楽坂の、カウンター8席だけのおまかせ寿司店。一晩に二回転で、仕込みはご予約の人数に合わせて朝から始まります。一組の無断キャンセルで、その夜の売上の一部と、そのお客さまのために仕入れた魚が無駄になります。電話での予約受付は営業中に手が止まり、前日の確認の電話も負担でした。スタッフに負担をかけず、お客さまにも失礼にならない形で、席を守りたい。

つくったもの

  1. LINEのメニューから開く予約画面。お名前はLINEのプロフィールから
  2. コース・日本酒のペアリング・人数を選ぶと、当日のお会計の目安を表示
  3. 二回転の空席を○△×で表示。満席の日はキャンセル待ちに登録
  4. アレルギー・苦手なもの・記念日などのご利用目的を、事前にお伺い
  5. カード登録（本日の請求¥0）か予約金の先払いで席を確保。キャンセルポリシーは確定の前に表示
  6. 予約の確認、3日前のお知らせ、前日の来店確認をLINEで。返事は台帳へ

設計で決めたこと

  1. カード番号はお店に届かないカードは決済会社の画面で入力します。お店に見えるのは「保証あり」の印だけで、請求はキャンセル料がかかるときだけです。
  2. 先に払わなくていい形を基本に予約金の先払いも選べますが、基本は本日¥0のカード登録。先に払うより、お客さまの負担が軽くなります。
  3. 決まりは、確定の前にキャンセル料（このデモでは2日前まで無料、前日50%、当日100%）を表で示し、同意のチェックをいただいてから確定します。
  4. 空いた席は、すぐ次の方へ前日にキャンセルが出ても、キャンセル待ちの方へLINEで自動でお知らせ。電話をかけ回る必要はありません。

実際の導入に必要なもの

  • お店のキャンセルポリシーを決めて、予約画面と店頭に同じ内容で表示
  • カードを登録して後から請求できる決済サービス（Stripeなど）との契約
  • LINE公式アカウントとLINEミニアプリのチャネル、LINEの審査
  • 予約と、前日などのお知らせを送る小さなサーバー
  • 電話や予約サイトからの予約も、同じ台帳に入れる運用
