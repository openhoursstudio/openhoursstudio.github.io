飲食 · LINEミニアプリ

席のQRから、LINEで注文してお会計まで

焼き鳥屋「鳥と炭」の席に置いたQRコードから、LINEの中で注文してお会計まで。アプリを入れずに使えるLINEミニアプリのモバイルオーダーと、注文を受け取る厨房の画面をつくりました。

ライブデモ

一杯と串を、頼んでみてください。

人数を選んで、串を何本かカートへ。注文を送ったら、そのままお会計まで進めます。パソコンでは、スマホの横に厨房のタブレットが並びます。スマホでは注文後の画面から開けます。実際の支払いは発生しません。

課題

二人で回す、カウンター十一席のお店。忙しい夜は焼き手が焼き台を離れられず、注文は店内に飛び交い、最後は小さなレジに行列ができます。お客さまが好きなときに串を少しずつ頼めて、待たずにお会計できるようにしたい。

つくったもの

  1. 席ごとのQRコード。読み取るとLINEの中でメニューが開き、アプリのインストールは不要
  2. 日本語と英語の写真付きメニュー。卵黄の有無やハイボールの濃さも選べる
  3. お通し代は人数分を自動で追加。価格はすべて税込表示
  4. 「受付済み→焼いています→お持ちしました」の進み具合を表示し、LINEにもお知らせ
  5. 割り勘表示つきのお会計。PayPay・カード・Apple Pay／Google Pay、またはレジで
  6. 注文を受け取って進める、厨房のタブレット画面

設計で決めたこと

  1. 新しいアプリではなく、LINEの中で日本のお客さまのほとんどがLINEを使っています。一度の食事のために、アプリを入れたい人はいません。
  2. 少しずつ頼んで、お会計は一度だけ焼き鳥は、そうやって食べるものだから。注文はそのたびに焼き台へ届き、最後にまとめて精算します。
  3. レジも、そのまま使えるスマホで払いたくない方もいます。現金や交通系ICは、これまでどおりレジで。
  4. また来たくなる仕掛け公式アカウントを友だち追加した方には、次回のクーポンを。お店からのお知らせも届けられます。

実際の導入に必要なもの

  • お店のLINE公式アカウント
  • LINEミニアプリのチャネル（LINEヤフーの審査は通常1〜2週間）
  • PayPayやカード会社などの決済サービスとの契約（手数料は売上の数％）
  • 特定商取引法に基づく表記とプライバシーポリシー（一緒に用意します）
  • 厨房のタブレットと、席に置くQRコード

使った技術

  • お客さま側はLINEミニアプリ（LIFF）
  • 手書きのHTML・CSS・JavaScript（フレームワーク不使用）
  • このデモはブラウザの中だけで動き、実際の注文や決済はしません
  • 写真はWikimedia Commons（CCライセンス、クレジット表記）
