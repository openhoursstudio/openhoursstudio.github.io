LINEミニアプリ · 珈琲店

並ばずに、
受け取るだけ

京都の珈琲店「かえでとケトル」のテイクアウト。LINEの公式アカウントのメニューから注文と支払いをすませ、受け取り時間を選ぶだけ。できあがったらLINEに届き、番号の札がついたカップを棚から持っていきます。

ライブデモ

自動で動いています。画面に触れると、そのまま操作できます。

お客さまの画面

読み取りから支払いまで、5つの画面

すべてLINEの中で完結します。アプリのインストールも、会員登録もいりません。

  1. 受け取り時間を選ぶできるだけ早く、または15分後・30分後・45分後。
  2. 写真付きメニュー珈琲、ほかの飲みもの、焼き菓子まで。
  3. ホットかアイスか温度やミルクを選んで。焼き菓子のおすすめも。
  4. LINEで先に支払いPayPay・カード・Apple Pay。お店では渡すだけ。
  5. 受け取り番号A-12のような番号と、できあがりのお知らせ。

お店側の画面

注文は、厨房のタブレットへ

新しいレジやプリンターは不要。厨房にあるタブレットやスマホが、そのまま注文の画面になります。

  • 注文は、受け取り時間と番号つきで届く
  • 「いれはじめる」「できあがり」を押すと、お客さまに届く
  • 今朝の注文の合計も、その場でわかる

課題

京都・北白川の小さな珈琲店。朝の八時台は、通勤や通学前のお客さまで店の外まで列が伸びます。一杯ずつハンドドリップで淹れるので、急ぐことはできません。待たせずに渡すには、注文を先にもらうしかありませんでした。

つくったもの

  1. 公式アカウントのメニューから開く、テイクアウト専用の注文画面
  2. 受け取り時間は「できるだけ早く」か、15分ごとに選べる
  3. ホットかアイス、牛乳かオーツミルクまで選べる写真付きメニュー
  4. 注文と同時に、LINEの中で支払い
  5. A-12のような受け取り番号と、できあがりのお知らせ
  6. 十個でドリンク一杯無料の、LINEスタンプカード

設計で決めたこと

  1. 席のQRではなく、公式アカウントからテイクアウトのお客さまは、お店に来る前に注文します。だから入り口は、トーク画面のメニューに。
  2. 時間がわかれば、淹れたてで渡せる受け取り時間がわかれば、ちょうどその時間に淹れたての一杯を用意できます。
  3. 先払いで、受け取り忘れを防ぐ支払いのすんだ注文だけを受けるので、作ったのに取りに来ない、が起きにくくなります。
  4. 店内で飲む方は、いつもどおりにLINEはテイクアウトのためだけ。店内のゆっくりした時間はこれまでどおりです。

実際の導入に必要なもの

  • お店のLINE公式アカウント
  • LINEミニアプリのチャネル（LINEヤフーの審査は通常1〜2週間）
  • PayPayやカード会社などの決済サービスとの契約（手数料は売上の数％）
  • 特定商取引法に基づく表記とプライバシーポリシー（一緒に用意します）
  • 厨房用のタブレットかスマホと、QRコード
