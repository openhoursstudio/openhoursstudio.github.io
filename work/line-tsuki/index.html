LINEミニアプリ · 美容室

電話の代わりに、
LINEで予約

中目黒のヘアサロン「月と櫛」。LINEのメニューから空いている時間を見て、メニューと担当を選んでそのまま予約。前日にはLINEでリマインドが届き、予約はお店の台帳にそのまま入ります。

ライブデモ

自動で動いています。画面に触れると、そのまま操作できます。

予約する人の画面

空きを見るところから予約まで、5つの画面

すべてLINEの中で完結します。アプリのインストールも、会員登録もいりません。

  1. トップ画面いちばん早い空き、人気のメニュー、来店スタンプ。
  2. メニューとオプショントリートメントやヘッドスパを足すと、料金と時間もその場で。
  3. 担当を選ぶ指名なしでも。担当ごとに、いちばん早い空きを表示。
  4. 空いている時間選んだメニューの時間がとれる枠だけ、選べます。
  5. 予約完了予約番号と、このあとLINEに届くもの。

お店側の画面

予約は、そのまま台帳へ

施術中に電話を取らなくても、予約が台帳に入ります。お店のタブレットやパソコンで、担当ごとの一日が見られます。

  • 予約は、担当と時間つきで台帳に入る
  • 日付を選ぶと、その日の台帳に切り替わる
  • 同じ時間に二つの予約が入ることはない

課題

席は四つ、スタイリストは同時に二人まで。施術中に鳴る電話には出られず、折り返すころには別のお店で予約されていることもありました。夜や休みの日でも、お客さまが自分で空きを見て予約できて、無断キャンセルも減らしたい。

つくったもの

  1. LINEのリッチメニューから開く予約画面。会員登録もパスワードもいらない
  2. メニューとオプション（トリートメント、ヘッドスパ）を選ぶと、料金と所要時間をその場で計算
  3. 担当の指名、または指名なし。担当ごとに、いちばん早い空きを表示
  4. 2週間分の空き状況。メニューの時間がとれる枠だけ選べる
  5. 初回20%オフとトップスタイリスト料金を、確認画面で自動計算
  6. 予約完了と前日のリマインドを、LINEでお知らせ

設計で決めたこと

  1. 電話より先に、LINEで若いお客さまほど、電話より文字で予約したい。いつものLINEなら、思い立ったその場で予約できます。
  2. 選べない時間は、見せない120分のメニューに、60分しか空いていない枠は出しません。電話での調整がいらなくなります。
  3. リマインドで、無断キャンセルを減らす前日のLINEが、予約を思い出すきっかけに。変更もそのメッセージからできます。
  4. お店のサイトと、同じ顔でメニュー・料金・スタッフは、「月と櫛」のホームページと同じ。どこから来ても、同じお店に見えます。

実際の導入に必要なもの

  • お店のLINE公式アカウント
  • LINEミニアプリのチャネル（LINEヤフーの審査は通常1〜2週間）
  • 予約台帳とのつなぎ込み（いまお使いの予約システムがあれば、それと連携）
  • プライバシーポリシー（一緒に用意します）
  • 台帳を見るタブレットかパソコン
