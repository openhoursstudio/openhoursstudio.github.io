5か国語で注文

浅草の居酒屋「ゆうなぎ」。席のQRから、英語・中国語（簡体字・繁体字）・韓国語のメニューで注文。アレルギーや豚肉・お酒などに印がつき、厨房には日本語の伝票で届きます。

ライブデモ

自動で動いています。画面に触れると、そのまま操作できます。

お客さまの画面

お客さまの言葉で、5つの画面

スマホのブラウザで開きます。旅行者にLINEやアプリ、会員登録は必要ありません。

  1. 言語を選ぶスマホの設定から自動で選び、いつでも変えられます。
  2. 食べられないものを選ぶアレルギー、ベジタリアン、豚肉、お酒。
  3. 印のついたメニュー料理ごとに日本語名と、含まれるものを表示。
  4. 日本語の伝票厨房に届いた内容を、お客さまも確認できます。
  5. お会計カード、Apple Pay、Alipay+やWeChat Pay、またはレジで。

お店側の画面

注文は、すべて日本語で届く

スタッフが外国語を話せなくても大丈夫。厨房にあるタブレットやスマホが、そのまま注文の画面になります。

  • お客さまの言語と、食べられないものが伝票のいちばん上に
  • 食べられないものに当たる料理には ⚠ の印
  • お水やお会計などのお願いも、日本語で届く

課題

浅草寺の近くの居酒屋。夜は半分ほどの席が海外からのお客さまです。写真を指さして注文を受け、アレルギーは手探り、お通しの説明にも困り、厨房に届くころには注文が違っていることも。お客さまは自分の言葉で読んで頼めて、厨房はこれまでどおり日本語で動けるようにしたい。

つくったもの

  1. 日本語・英語・中国語（簡体字・繁体字）・韓国語。スマホの設定から自動で選択
  2. アレルギー（表示義務の8品目と大豆・ごま・魚）、ベジタリアン、豚肉なし、アルコールなしを選ぶ画面
  3. 料理ごとに日本語名、含まれるもの、当てはまる場合の印。調理用の酒やみりんも対象に
  4. お通しとチップ不要を先に説明して、お会計で驚かせない
  5. 日本語の伝票。お客さまの言語と食べられないものをいちばん上に
  6. スタッフへのお願いボタン（お水・取り皿・おすすめ・お会計）と、最後にGoogleのレビュー案内

設計で決めたこと

  1. LINEはなくても動くLINEを使っていない旅行者が多いので、どのブラウザでも開けるように。日本のお客さまにはLINEの中からも開けます。
  2. 隠さずに、印をつける当てはまる料理も消さずに理由を示し、決めるのはお客さま。タレにみりんが入る焼き鳥は、自動で塩を選びます。
  3. 厨房は日本語のままスタッフが新しく覚えることはありません。伝票はいつもの注文と同じ形です。
  4. アレルギー表示は目安同じ厨房ですべての食材を扱うため、重いアレルギーの方にはスタッフへの声かけをお願いしています。

実際の導入に必要なもの

  • お店のメニューを一品ずつ、材料とアレルギーをご一緒に確認
  • 機械翻訳だけでなく、ネイティブによる翻訳の確認
  • 注文を受ける小さなサーバー（メニュー自体は普通のウェブページで動きます）
  • スマホで支払う場合は、海外カードやAlipay+・WeChat Payに対応した決済サービスとの契約
  • 厨房用のタブレットかスマホと、QRコード
