ライブデモ

自動で動いています。画面に触れると、そのまま操作できます。

お客さまの画面

読み取りから支払いまで、5つの画面

すべてLINEの中で完結します。アプリのインストールも、会員登録もいりません。

  1. 人数とコースを選ぶ飲み放題90分・120分、または単品で。
  2. 残り時間つきのメニュー飲み放題の残り時間が、いつも画面の上に。
  3. グラス交換制一回の注文で、お飲みものは人数分まで。
  4. 注文の進み具合受付済み、用意しています、お持ちしました。
  5. 割り勘でお会計お通しと飲み放題も入れて、一人あたりの金額まで。

お店側の画面

注文は、厨房のタブレットへ

新しいレジやプリンターは不要。厨房にあるタブレットやスマホが、そのまま注文の画面になります。

  • テーブル番号、人数、コースつきで注文が届く
  • 飲み放題のコースも、人数分で伝票に
  • 呼び出し（お水・取り皿など）も同じ画面に

課題

新橋の大衆酒場。宴会の多い店で、飲み放題の注文が重なると、ホールの二人では追いつきません。残り時間を聞かれ、ラストオーダーを伝えて回り、最後は割り勘の計算まで。席から頼めて、時間もお会計もひと目でわかるようにしたい。

つくったもの

  1. 人数と、飲み放題のコース（90分・120分・単品）を最初に選ぶ
  2. 飲み放題の残り時間を、メニューの上にいつも表示
  3. グラス交換制：一回の注文で、お飲みものは人数分まで
  4. ラストオーダーと終了の時間を、LINEでお知らせ
  5. お通しは人数分を自動で。割り勘表示つきのお会計
  6. お水やおしぼりを頼める、店員の呼び出しボタン

設計で決めたこと

  1. 時計は、いつも目に入る場所に残り時間をたずねる声がなくなれば、ホールはその分ほかの席に回れます。
  2. ルールは画面が守るグラス交換制は、注文の段階で自然に守れるように。店員が断る場面をつくりません。
  3. 割り勘まで、席で幹事さんがレジで計算しなくてすむよう、一人あたりの金額まで表示します。
  4. 単品の席も、同じ画面で飲み放題をつけない席も、同じ流れで注文できます。

実際の導入に必要なもの

  • お店のLINE公式アカウント
  • LINEミニアプリのチャネル（LINEヤフーの審査は通常1〜2週間）
  • PayPayやカード会社などの決済サービスとの契約（手数料は売上の数％）
  • 特定商取引法に基づく表記とプライバシーポリシー（一緒に用意します）
  • 厨房用のタブレットかスマホと、QRコード
