LINEミニアプリ · パン屋

会員証は、
LINEの中に

鎌倉のパン屋「こむぎ日和」。紙のポイントカードの代わりに、LINEの中の会員証。レジでバーコードを見せればポイントがたまり、クーポンもそのまま使えます。好きなパンの焼き上がりも、LINEでお知らせ。

ライブデモ

自動で動いています。画面に触れると、そのまま操作できます。

お客さまの画面

入会からポイントがたまるまで、5つの画面

すべてLINEの中で完結します。アプリのインストールも、会員登録もいりません。

  1. 入会の画面入会特典と、今日の焼き上がりの時間。
  2. LINE会員証ポイント、クーポン、焼き上がりのお知らせを一つの画面に。
  3. クーポン使う前に、条件と期限がわかる。
  4. レジで見せるバーコードとクーポン。表示してから5分間有効。
  5. ポイントがたまるレシートと、次のクーポンまでのポイント。

お店側の画面

レジで読み取るだけ

スマホの会員証のバーコードを読み取ると、ポイントとクーポンがその場で反映されます。紙のカードやスタンプは要りません。

  • 会員証を読み取ると、ポイントとクーポンが同時に反映
  • 会計中の品物と合計が、そのまま見られる
  • お使いのPOSレジとつなげれば、レジの操作はいつもどおり

課題

朝から行列のできるパン屋。紙のポイントカードは財布の中で忘れられ、レジでは「カードありますか」のやりとりで列が止まります。常連さんにもっと来てもらいたいけれど、焼きたての時間を知らせる手段もありませんでした。

つくったもの

  1. レジ横のQRから友だち追加して、そのまま入会。入会で100ポイント
  2. LINEの中の会員証。バーコードを見せればポイントがたまる
  3. 入会特典や雨の日のクーポン。条件と期限つきで、レジでそのまま使える
  4. 好きなパンを選んで、焼き上がりをLINEでお知らせ
  5. 100円で1ポイント。500ポイントで500円引きのクーポンに
  6. レシートもLINEに

設計で決めたこと

  1. 財布ではなく、スマホにLINEは毎日開くもの。会員証を忘れることがなくなります。
  2. 知らせるのは、本当に知りたいことだけ一斉のお知らせより、好きなパンの焼き上がり。ブロックされにくい使い方です。
  3. クーポンは、その場で使える形に表示してから5分間だけ有効。スクリーンショットの使い回しを防ぎます。
  4. レジの手間を増やさないバーコードを一度読み取るだけ。ポイントもクーポンも同時に反映されます。

実際の導入に必要なもの

  • お店のLINE公式アカウント
  • LINEミニアプリのチャネル（LINEヤフーの審査は通常1〜2週間）
  • お使いのPOSレジとの連携、またはレジ横のタブレットとバーコードリーダー
  • ポイントとクーポンの決まりと、プライバシーポリシー（一緒に用意します）
  • レジ横に置くQRコード
